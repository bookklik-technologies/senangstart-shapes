# SenangStart Shapes

Curated Starter shapes designed for web projects. `senangstart-shapes` provides a collection of 496 SVG assets across 302 shapes and 14 categories that can be easily used via the `ss-shape` web component or the `ss-shape ss-shape-<name>` classes. Shapes are designed to be simple & scalable, with solid, outline, duotone, and tonal styles.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE.md)

## Installation

```bash
npm i @bookklik/senangstart-shapes
```

## Usage

### Node.js / Bundlers

You can import the shapes collection using ES Modules (recommended) or CommonJS.

**ES Modules:**

```js
import shapes, { catalog } from '@bookklik/senangstart-shapes/shapes';

// Access specific shapes by SVG filename stem
const { 'soft-nova-duotone': SoftNova } = shapes;
```

**CommonJS:**

```js
const { shapes, catalog } = require('@bookklik/senangstart-shapes/shapes');

const { 'soft-nova-duotone': SoftNova } = shapes;
```

To register the web component in a bundled application:

```js
import '@bookklik/senangstart-shapes';
```

### Browser / Web Components

You may use the `<ss-shape>` tag:

```html
<head>
  <script src="https://unpkg.com/@bookklik/senangstart-shapes@0.1.2/dist/senangstart-shape.min.js"></script>
</head>
<body>
  <ss-shape shape="soft-nova" variant="duotone"></ss-shape>
</body>
```

> **Note:**
> Use paired tags in HTML. Omit `variant` to use the first available style in this order: solid, outline, duotone, tonal. Unknown shapes and unavailable variants render empty.
>
> Customize size with `font-size`, monochrome shapes with `color`, and duotones with `--ss-shape-primary` (default `#2563EB`) and `--ss-shape-secondary` (default `#DBEAFE`). A positive `thickness` value overrides existing strokes; otherwise, source stroke widths are preserved.
>
> Shapes are decorative by default. Add `aria-label` when a shape conveys meaning.

### CSS Shapes

Or use the `ss-shape` class:

```html
<head>
  <link
    rel="stylesheet"
    href="https://unpkg.com/@bookklik/senangstart-shapes@0.1.2/dist/senangstart.min.css"
  />
</head>
<body>
  <i class="ss-shape ss-shape-soft-nova"
     data-variant="duotone"
     aria-hidden="true"></i>
</body>
```

For bundlers, import `@bookklik/senangstart-shapes/style.css`.

CSS alone renders monochrome masks using the inherited text color. Loading the browser bundle enhances these elements with inline SVGs supporting both duotone colors and dynamically added elements.

## Curated Patterns

Twenty repeating SVG patterns compose existing shapes into ready-to-use backgrounds, from simple geometric repeats to layered botanical ornaments and expressive mixed-motif compositions. The original eight designs remain available alongside twelve additional variations:

- **Geometric:** Deco Fanfare, Tidal Counterpoint, Prism Parade, and Stepped Weave.
- **Botanical:** Wildflower Trail, Rosette Lattice, and Petal Pendant.
- **Expressive:** Lunar Procession, Ribbon Drift, Terrazzo Party, Celestial Atlas, and Serpentine Stripe.

Compositions include staggered trails, edge-wrapped motifs, nested outline-and-solid shapes, irregular scatter, ornamental medallions, and unequal stripes. Wide and tall tiles give each design its own rhythm rather than simply swapping shapes in the same grid.

```js
import '@bookklik/senangstart-shapes/patterns.css';
import patterns, { catalog } from '@bookklik/senangstart-shapes/patterns';
```

```html
<section class="ss-pattern-leaf-weave" style="min-height: 240px; --ss-pattern-size: 120px 120px"></section>
```

The stylesheet embeds the original palettes and requires no JavaScript. `patterns` maps slugs to SVG tile strings; `catalog` contains bilingual names and descriptions, categories, dimensions, colors, and source shapes. CommonJS is supported with `const { patterns, catalog } = require('@bookklik/senangstart-shapes/patterns')`.

Browse the **Patterns** page in the documentation to filter categories, change palettes and repeat scale, copy standalone CSS, or download customized SVG tiles. Generated tiles live in `dist/patterns/`. Pattern definitions live in `src/patterns/collection.json` and are regenerated by `npm run build`. Keep text on solid surfaces when patterned backgrounds reduce readability.
